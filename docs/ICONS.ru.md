# Иконки приложения Relay

*[English version](ICONS.md)*

«Настройки» → «Внешний вид» → **«Иконка приложения»** меняет иконку всех окон
Relay, кнопки на панели задач и значка в Dock на macOS. Иконку можно взять
четырьмя способами:

| Где | Что это |
|---|---|
| Карточки наверху | девять готовых иконок; **Relay** — исходная |
| **«Создать свою»** | редактор: форма, два цвета фона, значок или одна-две буквы, цвет значка |
| **«Иконки из плагинов»** | плагин «Пак иконок приложения» (18 иконок) или свой пак (раздел 4) |
| **«Мои иконки»** → **«Загрузить иконку…»** | своя картинка или JSON-файл с описанием иконки (разделы 2 и 3) |

Выбор сохраняется до следующего запуска. На Windows переключатель **«Иконка на
ярлыках Windows»** ставит её и на ярлыки установленного приложения — рабочий
стол, меню «Пуск» и значок, закреплённый на панели задач (Проводник может
перерисовать их не сразу). Иконка **Relay** возвращает исходную везде.

Сам файл приложения (`Relay.exe`, пакет `.app`) сохраняет встроенную иконку:
она — часть установщика.

---

## 1. Из чего состоит иконка

Иконка рисуется, а не хранится картинкой: **форма**, залитая **градиентом**
(от левого верхнего угла к правому нижнему), едва заметная светлая кайма и
сверху **значок** или **буквы** — так же устроена исходная иконка Relay. Для
окон Relay рисует её в 256×256, для карточек — меньше.

## 2. Своя картинка

**«Загрузить иконку…»** принимает PNG, JPEG, SVG, WebP, GIF, BMP и ICO.
Картинка вписывается в квадрат 256×256 (по центру, вокруг — прозрачность) и
хранится как PNG. Лучше всего подходит квадратная картинка с прозрачным фоном;
SVG отрисовывается один раз, в 256 px.

## 3. Описание иконки (JSON)

Тот же диалог принимает файл `.json` с одной иконкой, списком иконок или
`{ "icons": [ … ] }`:

```json
{
  "id": "night-shift",
  "name": "Ночная смена",
  "shape": "circle",
  "background": ["#30333f", "#15161d"],
  "glyph": "terminal",
  "glyphColor": "#5cf08a"
}
```

| Поле | Обязательно | Значения |
|---|---|---|
| `id` | нет (берётся имя файла) | строчные латинские буквы, цифры и `-`, до 64 символов |
| `name` | нет (берётся имя файла) | до 40 символов |
| `description` | нет | подсказка карточки, до 200 символов |
| `shape` | нет (`squircle`) | `squircle`, `circle`, `square`, `hexagon` |
| `background` | да | один цвет или список из 1–3 цветов для градиента |
| `glyph` | нет (`bolt`) | `bolt`, `send`, `star`, `braces`, `code`, `terminal`, `arrows`, `globe`, `pulse`, `plug`, `cube`, `flask`, `rocket`, `link`, `letter` |
| `letter` | при `glyph: "letter"` | одна или две буквы или цифры (любой алфавит) |
| `glyphColor` | нет (`#ffffff`) | цвет |
| `image` | нет | вместо рисунка: `data:image/png;base64,…`, до 400 КБ |

Цвета проверяются так же, как в темах: `#rgb`, `#rrggbb`, `rgb()`, `hsl()`,
`oklch()` и другие цветовые функции CSS или название цвета. Всё остальное, в том
числе `url(...)`, делает иконку недействительной, и она пропускается. Неизвестная
форма или значок заменяются формой и значком Relay.

## 4. Пак иконок

Пак — это папка с двумя файлами:

```
my-icon-pack/
├── plugin.json
└── icons.json
```

```json
{
  "id": "my-icon-pack",
  "name": "My Icon Pack",
  "description": "Two example app icons.",
  "version": "1.0.0",
  "capabilities": ["icons.extra"]
}
```

В `icons.json` — `{ "icons": [ … ] }` в формате раздела 3 (не больше 60 иконок;
к их id добавляется id пака; в паке `id` и `name` обязательны). Добавьте папку в «Настройки» → «Плагины» →
**«Выбрать плагин на компьютере…»** — её иконки появятся в разделе **«Иконки из
плагинов»**. Готовый пример — в
[`docs/plugin-guide/examples/my-icon-pack`](plugin-guide/examples/my-icon-pack),
встроенный пак — в [`plugins/icon-pack`](../plugins/icon-pack). Из пака ничего не
выполняется.

Иконка, выбранная из пака, продолжает работать, если пак выключить: Relay хранит её копию.
