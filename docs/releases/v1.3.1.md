## Relay 1.3.1

**Русский**

- **Раскладка ответа у каждой вкладки своя.** Положение и размер панели ответа запоминаются для каждой вкладки: растянули ответ до адресной строки на одной вкладке — на другой он останется таким, каким его там оставили. Раскладка переезжает вместе с вкладкой в другую панель.
- **Одинаковые зоны перетаскивания.** Навигация, ответ и зона запроса подсвечивают одни и те же четыре края; навигацию теперь можно закрепить и сверху.
- **Зона запроса переносится так же, как остальные панели** — за всю строку с названием запроса; в ней же кнопки положения. Перенос запроса меняет только раскладку своей панели и не сдвигает навигацию.
- **Вкладки переставляются перетаскиванием**, как в браузере.
- **Автоматические заголовки можно не отправлять.** На вкладке Headers кнопка с глазом (по умолчанию выключена) показывает Host, User-Agent, Accept, Accept-Encoding, Content-Type, Content-Length и Cookie со значениями; снятая галочка убирает заголовок из запроса. Host, Content-Length и Content-Type для form-data обязательны и не отключаются.
- **Запуск в терминале в Windows.** PowerShell больше не падает с «Базовое соединение закрыто: непредвиденная ошибка при передаче» при отключённой проверке SSL и с серверами только на TLS 1.3; при ошибке выводится её полная причина. curl в Windows не проверяет отзыв сертификатов (как и сам Relay), поэтому недоступный сервер CRL/OCSP не ломает запрос.

**English**

- **Response layout per tab.** The response position and size are remembered for each tab: stretch the response up to the URL bar on one tab and the next tab keeps its own layout. The layout moves with the tab to another pane.
- **One set of drop zones.** The navigation, the response and the request zone light up the same four edges; the navigation can now also dock at the top.
- **The request zone moves like the other panels** — by the whole row with the request name, which also carries the position buttons. Moving the request rearranges only its pane and leaves the navigation where it is.
- **Reorder tabs by dragging**, like browser tabs.
- **Automatic headers can be left out.** In the Headers tab the eye button (off by default) lists Host, User-Agent, Accept, Accept-Encoding, Content-Type, Content-Length and Cookie with their values; unticking one removes it from the request. Host, Content-Length and the form-data Content-Type are required and stay on.
- **Running in a terminal on Windows.** PowerShell no longer fails with «The underlying connection was closed: An unexpected error occurred on a send» with SSL verification off or against TLS 1.3-only servers, and prints the full cause of an error. curl on Windows skips certificate revocation checks (as Relay itself does), so an unreachable CRL/OCSP server does not fail the request.
