## Relay 1.3.5

**Русский**

- **Ответ можно скрыть, как навигацию.** Крестик в заголовке ответа, меню панели или Ctrl+Shift+B (на macOS ⌘+Shift+B) прячут ответ, и запрос занимает всю панель. Пока ответ скрыт, в строке с названием запроса есть кнопка «Показать ответ» с кодом последнего ответа. Скрытый ответ запоминается для каждой вкладки.
- **В узкой панели до всех кнопок можно добраться.** Когда вкладки запроса (Params, Authorization, Headers, Body, Scripts, Examples и кнопки «Сохранить», «Код», cURL) не помещаются, их строку теперь прокручивают колесо мыши, стрелки по краям и ползунок под ней. Так же прокручиваются вкладки ответа и полоски в Body и Scripts.
- **Длинный адрес:** у обрезанного края поля появляется кнопка «в конец» (или «в начало») — курсор сразу встаёт туда; колесо мыши тоже прокручивает адрес.
- **Заголовок ответа:** статус, время и размер прокручиваются, а кнопки положения панели всегда видны справа.
- **Узкие панели становятся компактнее:** у кнопок остаются только иконки, пять кнопок положения сворачиваются в одну с меню, а в очень узкой панели протокол и метод встают в одну строку, адрес и «Отправить» — в следующую.
- **Навигация и AI-панель уступают место:** в небольшом окне они сжимаются, а не сплющивают панели запросов.

**English**

- **The response can be hidden, like the sidebar.** The cross in the response header, the pane menu or Ctrl+Shift+B (⌘+Shift+B on macOS) hides the response and the request takes the whole pane. While it is hidden, the row with the request name carries «Show the response» with the code of the last response. A hidden response is remembered per tab.
- **Every button in a narrow pane is within reach.** When the request tabs (Params, Authorization, Headers, Body, Scripts, Examples and the Save, Code, cURL buttons) do not fit, their row now scrolls with the mouse wheel, the arrows at its ends and a slider under it. The response tabs and the Body and Scripts bars scroll the same way.
- **A long URL:** its clipped end gets a «to the end» (or «to the start») button that puts the caret there; the mouse wheel scrolls the URL too.
- **The response header:** the status, time and size scroll, and the panel's position buttons always stay in view on the right.
- **Narrow panels get compact:** buttons keep only their icons, the five position buttons fold into one with a menu, and in a very narrow pane the protocol and method share one row, the URL and Send the next.
- **The sidebar and the AI panel give way:** in a small window they shrink instead of squeezing the request panes.
