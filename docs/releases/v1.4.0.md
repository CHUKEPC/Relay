## Relay 1.4.0

**Русский**

- **Группы вкладок, как в браузере.** Правый клик по вкладке → «Добавить в новую группу» или «Добавить в группу». У группы есть название и цвет, её вкладки стоят рядом и подчёркнуты её цветом. Клик по ярлыку сворачивает группу до ярлыка со счётчиком и разворачивает обратно; правый клик открывает название, цвет и действия: новая вкладка в группе, разгруппировать, закрыть группу. Вкладки перетаскиваются в группу и из неё, ярлык — вместе со всей группой. «Открыть запросы группой вкладок» в меню папки или коллекции открывает все её запросы одной группой. Группы хранятся локально, в рабочем пространстве.
- **Корзина.** Удалённые запросы, папки, коллекции, среды, переменные, примеры ответов и очищенная история попадают в корзину (внизу боковой панели). Сразу после удаления их можно вернуть кнопкой «Восстановить» во всплывающем сообщении, позже — из корзины. Восстановленный элемент возвращается на прежнее место. Элементы хранятся 30 дней.
- **Ответ остаётся таким, каким его оставили.** При переключении вкладок у каждой сохраняются открытая вкладка ответа (Body, Headers, Cookies, Tests), режим Pretty/Raw/Preview, фильтр и прокрутка; редакторы тела и скриптов тоже помнят прокрутку.
- **Подсказки динамических переменных в теле и скриптах.** Список подсказок `{{` в редакторах кода был невидим (видны только иконки), а внутри строк JSON закрывался после `{{$`. Теперь `{{$randomInt}}`, `{{$guid}}` и другие подсказываются по мере ввода.
- **Длинное тело переносится, Beautify не сдаётся.** Вставленный однострочный JSON переносится по строкам автоматически. Beautify форматирует JSON с `{{переменными}}` без кавычек, а текст с лишними или недостающими скобками, комментариями и висячими запятыми выравнивает по скобкам, ничего не теряя.
- **OAuth 2.0: «Получить токен» понимает переменные.** Token URL вида `{{baseUrl}}/oauth/token`, Client ID и секрет из переменных теперь подставляются.
- **Невысокое окно:** низ боковой панели сворачивается в ряд иконок, и дереву коллекций хватает места.

**English**

- **Tab groups, like in a browser.** Right-click a tab → «Add to new group» or «Add to group». A group has a name and a colour; its tabs sit together, underlined in its colour. Clicking the label collapses the group to the label with a tab count and expands it again; right-clicking opens the name, colour and actions: new tab in group, ungroup, close group. Tabs drag into and out of a group, the label drags the whole group. «Open the requests as a tab group» in a folder or collection menu opens all its requests as one group. Groups are stored locally, in the workspace.
- **Trash.** Deleted requests, folders, collections, environments, variables, response examples and cleared history go to the trash (at the bottom of the sidebar). Right after deleting, «Restore» in the pop-up message brings an item back; later the trash does. A restored item returns to where it was. Items are kept for 30 days.
- **The response stays as you left it.** Switching tabs keeps each tab's open response tab (Body, Headers, Cookies, Tests), the Pretty/Raw/Preview view, the filter and the scroll position; the body and script editors keep their scroll too.
- **Dynamic variable hints in the body and scripts.** The `{{` suggestion list of the code editors was invisible (only the icons showed), and inside JSON strings it closed after `{{$`. `{{$randomInt}}`, `{{$guid}}` and the rest are now offered as you type.
- **Long bodies wrap, Beautify keeps going.** A pasted one-line JSON wraps automatically. Beautify formats JSON with unquoted `{{variables}}`, and re-indents text with extra or missing brackets, comments and trailing commas by its brackets, losing nothing.
- **OAuth 2.0: «Get token» understands variables.** A Token URL like `{{baseUrl}}/oauth/token`, a Client ID and a secret from variables are now resolved.
- **A low window:** the bottom of the sidebar folds into a row of icons, so the collection tree keeps its room.
