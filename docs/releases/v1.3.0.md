## Relay 1.3.0 — isolated desktop client for API testing

**Русский**

Relay теперь позиционируется как **изолированный десктопный клиент для тестирования API**: всё хранится у вас, без аккаунта и облака, а в сеть приложение выходит только по вашей команде. AI-ассистент остался необязательным комплектом.

- **Изоляция.** Убрана автоматическая проверка обновлений (и её переключатель) — версию можно проверить только кнопкой «Проверить сейчас». Отключены упреждающие DNS-запросы и проверка орфографии (она скачивает словари), все системные запросы разрешений (камера, геолокация, уведомления) отклоняются. Политика безопасности не пускает в окно внешние картинки и скрипты — в том числе в HTML-предпросмотре ответа.
- **Режим для слабых ПК** вместо «Экономить видеопамять»: после перезапуска — без видеоускорителя, анимаций, теней и размытия, с лёгким редактором вместо Monaco. Все возможности работают как обычно, подсказки `{{переменных}}` остаются.
- **Панели двигаются.** Боковую панель и панель ответа можно закрепить слева, справа, снизу или сделать плавающими — перетаскиванием заголовка (к краю — закрепить, в середину — плавающая) или кнопками в заголовке.
- **Свои темы.** «Настройки → Внешний вид → Мои темы → Загрузить тему…» принимает JSON-файл с цветами. Руководство для авторов тем — `docs/THEMES.ru.md` / `docs/THEMES.md`.
- **Палитра команд**: действия теперь вверху, запросы — ниже.
- **Протоколы** (проверены на локальных серверах, 61 тест): SSE снова работает на новых версиях Node и пишет причину переподключения, UTF-8 не бьётся на границах пакетов; WebSocket показывает настоящую причину ошибки рукопожатия и прерывает зависшее подключение через 30 с; MQTT отключается корректно (без рассылки Last Will); Socket.IO перестаёт бесконечно переподключаться; gRPC reflection подтягивает зависимые .proto; интроспекция GraphQL идёт по редиректам. В интерфейс добавлены логин/пароль/Client ID/подписки MQTT, подпротоколы WebSocket и фильтр событий Socket.IO. Соединения закрываются при перезагрузке окна.
- **Авторизация** (проверена по эталонным векторам спецификаций): подпись AWS для S3, EdgeGrid для PUT, Digest с `stale=true` и SHA-512-256, флаги NTLM, повторяющиеся поля в OAuth 1.0; подпись пересчитывается на каждом редиректе и никогда не создаётся для чужого хоста; криптостойкие nonce. **OAuth 2.0 — вход через браузер** с PKCE (S256) и `state`, код ловится на `http://127.0.0.1:порт` и сразу меняется на токен. Обновлённый токен сохраняется. Если авторизацию не удалось построить (битый JWT, неверный ключ), запрос не уходит без неё, а показывается ошибка. Импорт/экспорт Postman сохраняет AWS, Hawk, NTLM, OAuth 1.0, EdgeGrid, JWT и ASAP.
- **Резервные копии и данные**: повреждённый файл данных больше не затирается, повреждённый список рабочих пространств не теряет пространства; SQLite-копия выдерживает повторяющиеся id и посторонние строки; JSON/ZIP проверяются при восстановлении, «Добавить» не создаёт двойников; файл копии пишется атомарно, восстанавливаются копии до 256 МБ; экран «Данные» честно пишет, что входит в копию.
- **Интерфейс**: во вкладках протокольных запросов вместо «GET» — WS/SSE/MQTT/…; заголовок окна не ломается в узком окне; полосы прокрутки в цвет темы.
- **Документация на русском**: README, FEATURES, ARCHITECTURE, PLUGINS, AI_ASSISTANT и описания комплектов — рядом с английскими (`*.ru.md`). Справка в настройках дополнена разделами «Интерфейс и панели», «Протоколы и авторизация», «Изоляция и данные».

**English**

Relay is now positioned as an **isolated desktop client for API testing**: everything stays on your machine, no account, no cloud, and the app goes online only when you tell it to. The AI assistant remains an optional pack.

- **Isolation.** The automatic update check (and its switch) is gone — «Check now» is the only way. DNS prefetch and spellchecking (it downloads dictionaries) are off, every system permission request is declined, and the CSP keeps external images and scripts out of the window, including the HTML response preview.
- **Low-power mode** replaces «Save video memory»: after a restart — no GPU, no animations, shadows or blur, and a light editor instead of Monaco. Every feature keeps working, `{{variable}}` suggestions included.
- **Movable panels.** Dock the sidebar and the response panel left, right, at the bottom, or let them float — by dragging the header (edge to dock, middle to float) or with the buttons in it.
- **Your own themes.** Settings → Appearance → My themes → Load theme… takes a JSON file with colours. Guide: `docs/THEMES.md` / `docs/THEMES.ru.md`.
- **Command palette** lists actions first.
- **Protocols** (61 tests against local servers): SSE works on newer Node runtimes and reports why it reconnects; UTF-8 across chunk boundaries; real WebSocket handshake errors and a 30 s handshake timeout; graceful MQTT disconnect; Socket.IO stops after its retry budget; gRPC reflection loads dependencies; GraphQL introspection follows redirects. MQTT login/password/client id/subscriptions, WebSocket subprotocols and the Socket.IO event filter are now in the UI. Connections close when the window reloads.
- **Authorization** (spec vectors): AWS SigV4 for S3, EdgeGrid PUT, Digest `stale=true` and SHA-512-256, NTLM flags, repeated OAuth 1.0 form keys; signatures are recomputed per redirect hop and never minted for another host; cryptographic nonces. **OAuth 2.0 browser sign-in** with PKCE (S256) and `state`, caught on a loopback redirect and exchanged automatically. Refreshed tokens are stored. An auth that cannot be built stops the send with an error instead of sending unauthenticated. Postman import/export keeps AWS, Hawk, NTLM, OAuth 1.0, EdgeGrid, JWT and ASAP.
- **Backups and data**: a corrupt data file is set aside instead of overwritten; a corrupt workspace list no longer orphans workspaces; SQLite backups survive repeated ids and junk rows; JSON/ZIP restores are validated and «Add» no longer creates duplicates; backups are written atomically and restore up to 256 MB; the Data screen states honestly what a backup contains.
- **UI**: protocol requests show WS/SSE/MQTT/… instead of «GET»; the titlebar holds up in a narrow window; themed scrollbars.
- **Russian documentation** next to the English one (`*.ru.md`); Help gained «Interface and panels», «Protocols and authorization» and «Isolation and data».
