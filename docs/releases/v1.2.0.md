## Relay 1.2.0

**Русский**

- **Отправка в терминал.** Кнопка **cURL** рядом с «Код» сразу превращает запрос в команду curl и выполняет её в новом окне терминала (Windows Terminal / PowerShell, Terminal.app, gnome-terminal, konsole, xterm…). Стрелка рядом — HTTPie, wget (macOS/Linux) и PowerShell (Windows) и «Показать команду». Переменные, авторизация (включая Digest, NTLM и подписи AWS/OAuth 1/Hawk), тело, cookie, прокси и настройки SSL переносятся; всё экранируется, временные файлы удаляются после запуска.
- В «Код» добавлены **HTTP** (сырое сообщение, как в Postman) и **wget**, и кнопка «Выполнить в терминале». В самом приложении остались основные языки — cURL, HTTP, JavaScript и Python; Node, Go, Java, C#, PHP, Ruby, Swift, Kotlin, Rust, PowerShell, HTTPie и wget перенесены в плагин **«Генерация кода: другие языки»** (при обновлении он включается сам).
- **Импорт переменных** — глобальных, окружения и переменных коллекции — из экспорта Postman (окружение, глобальные, коллекция), JSON (в том числе вложенного, как у Insomnia), `.env` и CSV/TSV. Режимы «Объединить» и «Заменить все», предпросмотр до импорта. Кнопки — в разделе «Среды», в просмотре переменных (глаз) и в редакторах переменных.
- **Экспорт переменных** в те же форматы: окружение/глобальные Postman, JSON, `.env`, CSV. Значения секретных переменных по умолчанию не выгружаются. Файл читается обратно импортом.
- Появился **редактор переменных коллекции** (контекстное меню коллекции → «Переменные коллекции»).
- **Пак тем оформления** (плагин): Postman, Insomnia, Dracula, Nord, Tokyo Night, Catppuccin, Gruvbox, Solarized, One Dark, Synthwave ’84, Rosé Pine и авторские «Изумруд», «Глубина», «Закат», «Контраст». Редактор кода перекрашивается вместе с темой.
- **Сниппеты вынесены в плагин** «Сниппеты для скриптов» и пополнены проверками для каждого метода HTTP (201 + Location для POST, 204 и контрольный 404 для DELETE, Allow для OPTIONS…). При обновлении с 1.1 плагин включается сам; тема Postman/Insomnia сохраняется.
- **Шторка ответа**: при перетаскивании разделителя редакторы тела и скриптов растягиваются и сжимаются вместе с ней.
- **Руководство по созданию плагинов** (темы, сниппеты, кнопки, вкладки, изменение запросов, разрешения, примеры) — `docs/plugin-guide`, ссылка внизу «Настройки → Плагины».
- Исправлено: меню у кнопки cURL больше не уходит за край окна; в сгенерированном коде переменные `{{…}}` в параметрах остаются читаемыми, а пустое тело не превращается в `-d ''`.

**English**

- **Send to terminal.** The **cURL** button next to «Code» turns the request into a curl command and runs it in a new terminal window. The arrow offers HTTPie, wget (macOS/Linux), PowerShell (Windows) and «Show the command». Variables, auth (incl. Digest, NTLM, AWS/OAuth 1/Hawk signatures), body, cookies, proxy and SSL settings carry over; everything is escaped and the temporary files are removed after the run.
- Code generation gains **HTTP** (raw message) and **wget**, plus «Run in terminal». The core keeps cURL, HTTP, JavaScript and Python; the other twelve languages moved into the **«Code generation: more languages»** plugin (enabled automatically on upgrade).
- **Variable import** into globals, an environment or a collection from Postman exports, JSON (incl. nested, Insomnia style), `.env` and CSV/TSV, with merge / replace and a preview.
- **Variable export** to the same formats (Postman environment/globals, JSON, `.env`, CSV); secret values stay out unless you include them.
- A **collection variables editor** (collection context menu → «Collection variables»).
- **Theme pack** plugin with 15 themes, including Postman and Insomnia; code editors follow the theme.
- **Script snippets moved into a plugin** and extended with checks for every HTTP method. Upgrading from 1.1 enables it automatically and keeps a Postman/Insomnia theme.
- Dragging the response divider now resizes the body and script editors with it.
- **Plugin authoring guide** in `docs/plugin-guide`, linked from Settings → Plugins.
- Fixed: the cURL button menu no longer runs off the window edge; generated code keeps `{{…}}` variables in query parameters readable and no longer turns an empty body into `-d ''`.
