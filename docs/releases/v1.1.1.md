## Relay 1.1.1

**Русский**

- Скрипты и плагины снова работают в установленном приложении (в 1.0 песочница падала в собранной версии).
- Раннер: выбор коллекции или папки больше не прячется под окном; прогон со скриптами в разы быстрее и не грузит процессор (песочница переиспользуется).
- Подсказка переменных: после ввода `{{` появляется список доступных переменных.
- «Проверка SSL» выключена — значит выключена на всех редиректах; при ошибке сертификата есть кнопка «Отключить проверку SSL и повторить».
- `pm.sendRequest` отправляет тела `urlencoded`, `formdata` (текст), `graphql` и `raw` как в Postman; `console.log(error)` показывает текст ошибки.
- Горячие клавиши разделения панелей больше не конфликтуют с системными; FAQ объясняет, какие функции подключаются плагинами.

**English**

- Scripts and plugins work again in the installed app (the sandbox crashed in packaged 1.0 builds).
- Runner: the collection/folder picker is no longer hidden behind the dialog; scripted runs are many times faster and no longer pin the CPU (the sandbox is reused).
- Variable hints: typing `{{` lists the variables in scope.
- Turning SSL verification off now holds across redirects; a certificate error offers «disable verification and retry».
- `pm.sendRequest` sends `urlencoded`, `formdata` (text), `graphql` and `raw` bodies like Postman; `console.log(error)` prints the message.
- Pane-split shortcuts no longer clash with system ones; the FAQ explains which features come from plugins.
