# Как сделать свою тему для Relay

*[English version](THEMES.md)*

Тема Relay — это один JSON-файл. Никакой код не выполняется и ничего не
устанавливается: «Настройки → Внешний вид → **Мои темы** → **Загрузить тему…**»
читает файл, проверяет каждое значение и добавляет тему в список. В том же
формате темы поставляет *пак тем* (`plugins/theme-pack/themes.json`), поэтому
написанный здесь файл позже можно превратить в пак без изменений.

---

## 1. Самая короткая рабочая тема

```json
{
  "id": "midnight",
  "name": "Midnight",
  "description": "Глубокий синий, мягкий контраст",
  "accent": "#7aa2f7",
  "variants": {
    "dark": {
      "--bg-0": "#0f1016",
      "--bg-1": "#161822",
      "--bg-2": "#1d2030",
      "--tx-0": "#e6e8f0",
      "--tx-2": "#9aa0b4",
      "--line": "#252938"
    }
  }
}
```

Сохраните как `midnight.json` и загрузите. Это весь рабочий цикл.

В одном файле может быть и **несколько** тем — простым списком или в обёртке,
которую использует пак. Загружаются все три варианта:

```json
{ "themes": [ { "id": "one", "name": "One", "variants": { … } },
              { "id": "two", "name": "Two", "variants": { … } } ] }
```

---

## 2. Поля

| Поле | Обязательно | Что значит |
|---|---|---|
| `id` | да | Строчный слаг (`a-z`, `0-9`, `-`), до 64 символов, уникальный. Файл с уже существующим id **заменяет** ту тему. |
| `name` | да | Подпись на карточке, до 40 символов. Файл с одной темой без имени берёт имя файла. |
| `description` | нет | Всплывающая подсказка на карточке. |
| `accent` | нет | Акцентный цвет. Если его нет, берётся `--accent` из варианта; если нет и его — остаётся акцент Relay. |
| `variants.dark` | одно из двух | CSS-переменные для тёмного режима. |
| `variants.light` | одно из двух | То же для светлого. |

Тема с одним вариантом — это нормально: на карточке появится луна или солнце, и
тема будет выглядеть одинаково при любом положении переключателя «Тёмная /
Светлая / Системная». Тема с двумя вариантами следует за переключателем.

---

## 3. Переменные

Каждое значение — это CSS-переменная. Ниже те, что имеет смысл задавать; всё,
что вы не указали, останется как в Relay, поэтому маленькая тема — тоже
полноценная тема.

**Поверхности**

| Переменная | Что красит |
|---|---|
| `--bg-0` | фон окна, редакторы |
| `--bg-1` | боковая панель, заголовок окна, панели |
| `--bg-2` | строки, поля ввода, карточки |
| `--bg-3` | приподнятые поверхности (меню, чипы) |
| `--bg-hover`, `--bg-active` | наведение и нажатие |
| `--line`, `--line-2` | все линии и границы |
| `--code-bg` | фон редактора кода |

**Текст**

| Переменная | Что красит |
|---|---|
| `--tx-0` | заголовки и основной текст |
| `--tx-1` | текст интерфейса |
| `--tx-2` | вторичный текст, описания |
| `--tx-3` | подсказки в полях, недоступное |

**Акцент**

| Переменная | Что красит |
|---|---|
| `--accent` | кнопки, активная вкладка, фокус |
| `--accent-hover`, `--accent-press` | два его состояния (выводятся сами, если не заданы) |
| `--accent-soft`, `--accent-soft-2` | подложки под акцентом |
| `--accent-fg` | текст поверх акцента |

**Статусы, методы и код**

| Переменная | Что красит |
|---|---|
| `--s-2xx`, `--s-3xx`, `--s-4xx`, `--s-5xx` | коды ответа |
| `--m-get`, `--m-post`, `--m-put`, `--m-patch`, `--m-delete`, `--m-head`, `--m-options` | цвета HTTP-методов |
| `--c-key`, `--c-str`, `--c-num`, `--c-bool`, `--c-null`, `--c-punct` | подсветка JSON |

Редактор кода перекрашивается вместе с темой сам: его палитра выводится из этих
же переменных, отдельно цвета редактора писать не нужно. Полный список
переменных, которые можно задать, — это то, что объявлено на `:root` в
`src/renderer/styles/base.css`.

---

## 4. Какие значения разрешены

Тема — это данные, а не код, поэтому загрузчик принимает только «цветоподобные»
значения, а остальные отбрасывает:

- hex — `#abc`, `#aabbcc`, `#aabbccdd`;
- цветовые функции — `rgb()`, `rgba()`, `hsl()`, `hsla()`, `oklch()`, `oklab()`, `lab()`, `lch()`, `hwb()`;
- ключевые слова вроде `transparent`, `currentColor`, `inherit`;
- числа и простые размеры (`0`, `6px`, `1.5`) для немногих нецветовых переменных.

`url(...)`, `expression(...)`, `@import`, JavaScript, HTML и всё, где есть `<`,
`>` или точка с запятой, отбрасываются. Отброшенное значение просто
пропускается — остальная тема всё равно загрузится.

Не разрешены (чтобы не гадать, почему значение проигнорировано): `color-mix()`,
`var()`, градиенты и любые другие функции вне списка выше.

Ограничения: 512 КБ на файл, 40 тем в одном файле и 60 сохранённых всего, 200
символов на значение, 80 переменных на вариант, 40 символов на имя и 200 на
описание.

## 5. Как подобрать цвета, не угадывая

Самый быстрый цикл: откройте Relay в том виде, который хотите изменить, откройте
инструменты разработчика (`Ctrl+Shift+I` в dev-сборке), поправьте `--bg-0`,
`--tx-0` и остальные прямо на `<html>`, а затем перенесите устроившие значения в
файл. Повторная загрузка файла заменяет тему на месте, так что цикл — это
«сохранить, загрузить снова».

Чтобы получилось читаемо:

- держите контраст не ниже 4.5:1 между `--tx-1` и `--bg-0` и не ниже 3:1 между
  `--tx-2` и поверхностью под ним;
- `--line` должен быть близок к разделяемой поверхности: линия ярче текста
  превращает интерфейс в клетку;
- акцент должен быть различим и на `--bg-1`, и на `--bg-2` — активная вкладка и
  главная кнопка лежат на разных поверхностях;
- цвета статусов должны различаться в обоих режимах: зелёный и красный одинаковой
  светлоты неразличимы для заметной доли людей.

15 встроенных тем в `plugins/theme-pack/themes.json` — рабочий пример: Postman,
Insomnia, Dracula, Nord, Tokyo Night, Catppuccin, Gruvbox, Solarized, One Dark,
Synthwave ’84, Rosé Pine и четыре авторские.

## 6. От файла к паку

Чтобы поделиться набором тем, оформите их паком, а не файлом:

```
my-theme-pack/
├── plugin.json     → { "id": "my-theme-pack", "capabilities": ["themes.extra"], … }
└── themes.json     → { "themes": [ … ] }
```

Папка ставится в «Настройки → Плагины → **Выбрать плагин на компьютере…**».
Полный формат манифеста описан в
[руководстве по плагинам](plugin-guide/README.ru.md) ([in English](plugin-guide/README.md)).

## 7. Что делать, если не получилось

| Что видно | Почему |
|---|---|
| «Это не JSON-файл» | Лишняя запятая, одинарные кавычки или комментарий — в JSON их нельзя. |
| «В файле нет ни одной темы в понятном формате» | Нет `id` или он не слаг, нет `name`, либо в `variants` нет ни `dark`, ни `light`. |
| Тема загрузилась, но ничего не изменилось | Опечатка в именах переменных: все они начинаются с `--`. |
| Часть цветов не применилась | Эти значения не прошли проверку из §4. |
| Тема пропала после перезапуска | Её заменил другой файл с тем же `id`. |
