# Комплекты возможностей

*[English version](README.md)*

Эта папка поставляется рядом с приложением и определяет, что Relay умеет сверх базового набора:
HTTP-запросов, шести распространённых схем авторизации, русского и английского языков и не более четырёх
панелей.

Каждая вложенная папка — это один комплект с манифестом `plugin.json`:

```json
{
  "id": "websocket",
  "name": "WebSocket",
  "description": "Shown in Settings → Plugins",
  "version": "1.0.0",
  "capabilities": ["protocol.websocket"]
}
```

`id` должен совпадать с именем папки. Всё декларативно — комплект возможностей
никогда не выполняет код, и именно этим он отличается от пользовательского плагина
(`docs/PLUGINS.md`, работает в песочнице и только с выданными разрешениями).

| Возможность | Что открывает |
|---|---|
| `protocol.websocket` / `protocol.sse` / `protocol.socketio` / `protocol.mqtt` / `protocol.grpc` | соответствующий пункт в выборе протокола |
| `ai` | панель AI-ассистента, её сочетание клавиш и раздел Настройки → AI-провайдеры |
| `auth.advanced` | Digest, JWT, OAuth 1.0, AWS Signature v4, Hawk, Akamai, ASAP, NTLM |
| `i18n.extra` | языки интерфейса, перечисленные в `locales` |
| `panes.extra` | до 16 панелей вместо четырёх и пресет на 8 панелей |
| `backup.extra` | резервные копии в ZIP и SQLite |
| `snippets` | панель сниппетов на вкладке Scripts, заполняемая из `snippets.json` комплекта |
| `themes.extra` | цветовые темы в Настройки → Внешний вид, из `themes.json` комплекта |
| `codegen.extra` | ещё двенадцать языков в окне «Код» (Node, Go, Java, C#, PHP, Ruby, Swift, Kotlin, Rust, PowerShell, HTTPie, wget) |

Комплекты сниппетов и тем хранят свои данные рядом с манифестом; форматы,
полный список токенов и готовые к копированию примеры — в
[`docs/plugin-guide`](../docs/plugin-guide/README.ru.md).

Удаление папки убирает возможность; выключение комплекта в
Настройки → Плагины скрывает её, пока комплект снова не включат. Состояние
включения/выключения хранится отдельно для каждой установки, а не в этой папке.

## Добавление языка интерфейса

`extra-languages` читает `locales/<code>.json`. Чтобы добавить язык:

1. скопируйте `locales/en.json` из исходного кода приложения (или один из уже лежащих здесь файлов),
2. переведите значения — **ключи — это исходные русские строки**, и они должны
   остаться в точности такими, как есть,
3. сохраните файл как `locales/<code>.json` (например, `it.json`),
4. добавьте код языка в `"locales"` в `plugin.json`,
5. перезапустите Relay и выберите язык в Настройки → Основные.

Недостающие ключи показываются по-английски, а если нет и английского — исходной русской строкой, поэтому частичным
каталогом можно пользоваться с первой же строки.
